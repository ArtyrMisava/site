ДАННЫЕ ДУС
===========

При запуске через START_SITE_WINDOWS.bat переносной сервер автоматически создаёт
в этой папке файл dus-data.json и резервную копию dus-data.json.bak.

В них сохраняются:
- защищённый хеш PIN администратора (сам PIN не сохраняется);
- хеш кода восстановления;
- точки, сотрудники, пользовательские иконки;
- машины, маршруты и настройки карты.

Не редактируйте JSON вручную. Для переноса установки копируйте всю папку ДУС
вместе с site-data. Перед обновлением рекомендуется сделать резервную копию.

Для аварийного сброса доступа используйте RESET_ADMIN_PASSWORD.bat. Точки,
машины и маршруты при таком сбросе не удаляются.
