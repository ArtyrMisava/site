# ДУС — локальная карта объектов

ДУС — полностью офлайн-сайт для рабочих точек, сотрудников и служебных машин. Карта, данные и готовая Windows-сборка находятся внутри проекта; интернет для работы не нужен.

## Быстрый запуск на Windows

1. Скачайте и полностью распакуйте ZIP проекта.
2. Дважды нажмите `START_SITE_WINDOWS.bat`.
3. Не закрывайте появившееся окно, пока работаете с сайтом.

Сайт откроется в Microsoft Edge или Google Chrome. Node.js и `npm` для обычного запуска не нужны: BAT запускает готовую папку `offline-site` через локальный PowerShell-сервер.

## Что умеет ДУС

- показывает офлайн-карту Восточной Европы;
- добавляет и редактирует точки и машины;
- позволяет менять иконки точек, включая спутник, домики и собственные изображения;
- показывает ближайший населённый пункт над каждой пользовательской меткой;
- хранит сотрудников точки в связанной книге Excel;
- строит маршруты машин и показывает движение и направление;
- открывает отдельное интерактивное окно карты для второго монитора и при необходимости связывает обзор двух карт;
- сохраняет данные локально на этом компьютере;
- поддерживает полноэкранный режим и не позволяет уйти за границы карты.

## Администратор и место хранения учётной записи

Учётная запись администратора **не хранится в файлах папки сайта** и никуда не отправляется. Она сохраняется в локальном хранилище профиля браузера для адреса, на котором открыт ДУС, например `http://127.0.0.1:4173`.

Внутренние ключи:

- `lokus-admin-credentials-v1` — имя администратора и SHA-256-хеш PIN;
- `lokus-admin-session-v1` — временная активная сессия;
- `lokus-map-items-v1` — точки, машины и маршруты.

Физическая папка хранилища на Windows обычно находится здесь:

- Microsoft Edge: `%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Local Storage\leveldb\`
- Google Chrome: `%LOCALAPPDATA%\Google\Chrome\User Data\Default\Local Storage\leveldb\`

Если используется другой профиль браузера, вместо `Default` будет `Profile 1`, `Profile 2` и т. п. Файлы LevelDB нельзя редактировать вручную. Для просмотра или удаления данных используйте инструменты браузера: `F12` → **Application / Приложение** → **Local Storage** → локальный адрес ДУС.

Важно: хранилище привязано к браузеру, его профилю и точному адресу с портом. Если очистить данные сайта, сменить профиль или запустить ДУС на другом порту, сохранённая учётная запись в новом адресе не появится. PIN в открытом виде не сохраняется.

## Связь с Excel

Функция работает в Edge и Chrome. В режиме администратора нажмите **«Привязать Excel»** и выберите `.xlsx`.

Формат книги:

- один обычный лист — одна точка;
- название листа — название точки;
- `A1` пустая, `B1` содержит название точки;
- со строки 2: столбец `A` — ФИО, столбец `B` — звание или должность.

Сайт создаёт скрытый служебный лист `_Карта` для ID, координат и выбранных иконок. Создание, переименование, перемещение и удаление точки обновляют ту же книгу. Не держите книгу открытой в настольном Excel во время сохранения. Пример: `public/templates/points-workbook-template.xlsx`.

## Иконки точек

Откройте точку в режиме администратора и выберите иконку в разделе **«Иконка точки»**. В комплект входят обычная метка, офис, дом, домики, склад, КПП, спутник и штаб. Любую существующую метку можно открыть и заменить её иконку.

Для собственной иконки нажмите **«Загрузить свою»** и выберите PNG, JPG, WebP или SVG размером до 5 МБ. Изображение автоматически уменьшается, сохраняется локально вместе с точкой и продолжает работать без интернета. Встроенные файлы находятся в `public/icons/places`, а в готовой Windows-сборке — в `offline-site/icons/places`.

## Маршрут машины

1. Войдите как администратор.
2. Откройте машину и нажмите **«Задать маршрут»**.
3. Отметьте точки пути на карте.
4. Нажмите **«Запустить»**.

Машина движется по линии маршрута. Её значок не вращается — направление показывает отдельная стрелка. Одна реальная секунда соответствует одной минуте пути с заданной скоростью.

## Отдельная карта

Кнопка **«Отдельная карта»** открывает синхронизированное интерактивное окно. Его можно перенести на второй монитор. По умолчанию обзор карт связан: перемещение и масштабирование в одном окне повторяются в другом. Кнопка **«Карты связаны»** в любом из окон отключает привязку и включает **«Независимый обзор»**; повторное нажатие снова связывает карты. Объекты, маршруты и движение синхронизируются локально в обоих режимах.

## Офлайн-карта

Охват: 14–60° в.д. и 38–61° с.ш. — от Польши и Балкан до Урала и Каспийского моря. Используются 540 локальных WebP-тайлов и локальная база из 37 381 населённого пункта. Подписи показываются по масштабу: от столиц и крупных городов на общем обзоре до районных центров, малых городов, посёлков, сёл и частей городов при приближении. При работе обращения к внешним картографическим сервисам не выполняются.

Основа карты — [Natural Earth](https://www.naturalearthdata.com/) (public domain), населённые пункты — [GeoNames](https://www.geonames.org/) (CC BY 4.0). Сведения об используемых данных находятся в `public/maps/MAP_DATA_RU.txt`.

## Разработка

Для изменения исходного кода нужен Node.js LTS:

```bash
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run check
npm run build
```

После сборки содержимое `dist` копируется в `offline-site` для запуска через BAT.
