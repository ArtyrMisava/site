# Локус — локальная карта объектов

Одностраничный офлайн-интерфейс для размещения сотрудников, рабочих точек и служебных машин на карте компании.

## Возможности прототипа

- условная городская карта, работающая без интернета;
- увеличенная область наведения у каждой метки;
- карточка-таблица с именем, фамилией и названием точки;
- служебные машины со статусом и направлением движения;
- поиск и фильтрация объектов;
- режим администратора с первичной настройкой имени и PIN;
- добавление, редактирование, удаление и перетаскивание объектов;
- автоматическое сохранение данных в браузере этого компьютера;
- адаптивный интерфейс для разных размеров экрана.

## Запуск для разработки

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:4173`).

## Проверка и production-сборка

```bash
npm run check
npm run build
npm run preview
```

Готовые статические файлы появляются в каталоге `dist` и не требуют доступа к интернету.

## Данные и доступ администратора

При первом нажатии кнопки «Администратор» приложение предложит создать локальное имя пользователя и PIN. PIN хранится в браузере в виде SHA-256-хеша. Объекты карты сохраняются в `localStorage`, а активная административная сессия — в `sessionStorage`.

> Это подход для выбранного сценария одного локального компьютера. Если сайт понадобится нескольким сотрудникам одновременно, хранение и авторизацию следует перенести на локальный сервер с базой данных.
