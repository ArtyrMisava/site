# ДУС — локальная карта объектов

ДУС — полностью офлайн-сайт для рабочих точек, сотрудников и служебных машин. Карта, русские географические подписи, данные и готовая Windows-сборка находятся внутри проекта; интернет для работы не нужен.

## Быстрый запуск на Windows

1. Скачайте и полностью распакуйте ZIP проекта в папку, где у пользователя есть право записи, например в `Документы\ДУС`.
2. Дважды нажмите `START_SITE_WINDOWS.bat`.
3. Не закрывайте появившееся окно, пока работаете с сайтом.

Основной способ запуска использует `runtime\DUS_SERVER.exe`. Это переносной локальный сервер: ему не нужны PowerShell, Node.js, `npm`, установка и права администратора. Он слушает только адрес компьютера `127.0.0.1`, открывает Edge или Chrome и показывает путь к файлу данных. PowerShell оставлен только как совместимый резервный вариант на случай удаления EXE.

## Что умеет ДУС

- показывает полностью локальную карту Восточной Европы;
- выводит 37 381 населённый пункт русскими буквами;
- добавляет и редактирует точки и машины;
- позволяет менять иконки точек, включая спутник, домики и собственные изображения;
- показывает ближайший населённый пункт над каждой пользовательской меткой;
- хранит сотрудников точки в связанной книге Excel;
- строит маршруты машин и показывает движение и направление;
- открывает отдельное интерактивное окно карты для второго монитора;
- сохраняет точки, машины, маршруты, настройки и защищённые данные доступа в папке сайта;
- поддерживает полноэкранный режим и не позволяет уйти за границы карты.

## Слои и детализация карты

Кнопка **«Слои карты»** в правом верхнем углу карты предлагает четыре режима:

- **Авто** — обзор, подробная и максимальная карта переключаются при приближении;
- **Обзор** — обзорный слой остаётся включённым при любом масштабе;
- **Подробно** — дороги, реки, города и посёлки доступны независимо от приближения;
- **Максимум** — принудительно используются наиболее подробные локальные тайлы и подписи сёл.

Выбранный режим сохраняется в папке данных и применяется также в отдельном окне карты. Чтобы снова переключать слои приближением, выберите **«Авто»**.

## Где хранятся данные

При официальном запуске рядом с сайтом автоматически создаются:

- `site-data\dus-data.json` — текущие данные;
- `site-data\dus-data.json.bak` — предыдущая автоматическая копия.

В файл входят точки, сотрудники, пользовательские иконки, машины, маршруты, настройки карты и данные учётной записи. Сам PIN и код восстановления **никогда не записываются открытым текстом**: сохраняются только их индивидуально засоленные PBKDF2-SHA-256-хеши. Не редактируйте JSON вручную.

Старые данные из браузерного `localStorage` автоматически переносятся в `site-data` при первом запуске обновлённой версии на прежнем адресе `http://127.0.0.1:4173`. Браузерное хранилище остаётся локальным кэшем совместимости. Для переноса на другой компьютер копируйте всю папку ДУС вместе с `site-data`.

Связанная книга `.xlsx` остаётся отдельным пользовательским файлом в выбранном вами месте. В `site-data` сохраняется карта и копия данных точек, но сайт не перемещает исходную Excel-книгу без разрешения пользователя.

## Администратор и восстановление PIN

При создании администратора сайт один раз показывает код вида `XXXX-XXXX-XXXX-XXXX`. Сохраните его отдельно от компьютера. На экране входа кнопка **«Забыли PIN? Восстановить»** позволяет ввести имя, этот код и новый PIN. Точки, машины и маршруты при восстановлении не удаляются.

Для старой учётной записи, у которой ещё нет кода, или при полной утрате кода:

1. закройте окна сайта и окно локального сервера;
2. запустите `RESET_ADMIN_PASSWORD.bat`;
3. введите `RESET` для подтверждения;
4. снова запустите ДУС и создайте новую учётную запись.

BAT удаляет только учётные данные администратора. Объекты карты и настройки сохраняются. Любой человек с доступом на запись к папке ДУС сможет запустить этот BAT, поэтому ограничьте доступ к самой папке средствами Windows.

## Обновление существующей установки

1. Распакуйте новую версию в отдельную временную папку.
2. Закройте браузер с ДУС и старое окно сервера.
3. В **новой** папке запустите `UPDATE_EXISTING_SITE.bat`.
4. Введите путь к старой папке ДУС или перетащите её в окно CMD.
5. После сообщения `UPDATE COMPLETED` запускайте `START_SITE_WINDOWS.bat` уже из старой папки.

Обновлятор заменяет программу, карту и встроенные ресурсы, но не трогает `site-data`. Предыдущие программные файлы сохраняются в `update-backup`. При обновлении очень старой версии точки и учётная запись будут перенесены из браузера в папку во время первого запуска; поэтому важно сохранить прежний адрес и порт `4173`.

## Связь с Excel

Функция работает в Edge и Chrome. В режиме администратора нажмите **«Привязать Excel»** и выберите `.xlsx`.

Формат книги:

- один обычный лист — одна точка;
- название листа — название точки;
- `A1` пустая, `B1` содержит название точки;
- со строки 2: столбец `A` — ФИО, столбец `B` — звание или должность.

Сайт создаёт скрытый служебный лист `_Карта` для ID, координат и выбранных иконок. Создание, переименование, перемещение и удаление точки обновляют ту же книгу. Не держите книгу открытой в настольном Excel во время сохранения. Пример: `public/templates/points-workbook-template.xlsx`.

## Иконки точек

Откройте точку в режиме администратора и выберите иконку в разделе **«Иконка точки»**. В комплект входят обычная метка, офис, дом, домики, склад, КПП, спутник и штаб. Любую существующую метку можно открыть и заменить её иконку.

Для собственной иконки нажмите **«Загрузить свою»** и выберите PNG, JPG, WebP или SVG размером до 5 МБ. Изображение автоматически уменьшается, сохраняется вместе с точкой и продолжает работать без интернета. Встроенные файлы находятся в `public/icons/places`, а в готовой Windows-сборке — в `offline-site/icons/places`.

## Маршрут машины

1. Войдите как администратор.
2. Откройте машину и нажмите **«Задать маршрут»**.
3. Отметьте точки пути на карте.
4. Нажмите **«Запустить»**.

Машина движется по линии маршрута. Её значок не вращается — направление показывает отдельная стрелка. Одна реальная секунда соответствует одной минуте пути с заданной скоростью.

## Отдельная карта

Кнопка **«Отдельная карта»** открывает синхронизированное интерактивное окно. Его можно перенести на второй монитор. По умолчанию обзор карт связан; кнопка **«Карты связаны»** включает независимый обзор и обратно. Объекты, слои, маршруты и движение синхронизируются локально.

## Офлайн-карта и русские названия

Охват: 14–60° в.д. и 38–61° с.ш. — от Польши и Балкан до Урала и Каспийского моря. Используются 540 локальных WebP-тайлов и локальная база из 37 381 населённого пункта. Все названия населённых пунктов проверяются сборочным скриптом: латинские и локальные написания преобразуются в русские формы, включая исправление `Новий Крим` / `Novyi Krym` на **«Новый Крым»**. При работе обращения к внешним картографическим сервисам не выполняются.

Основа карты — [Natural Earth](https://www.naturalearthdata.com/) (public domain), населённые пункты — [GeoNames](https://www.geonames.org/) (CC BY 4.0). Сведения об используемых данных находятся в `public/maps/MAP_DATA_RU.txt`.

## Разработка

Для изменения исходного кода нужен Node.js LTS:

```bash
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run check
npm run build
python scripts/russianize-place-labels.py public/maps/places.json
```

После сборки содержимое `dist` копируется в `offline-site`. Переносной сервер собирается воспроизводимым workflow `.github/workflows/build-dus-server.yml`; исходный код находится в `server/dus-server.go`.
