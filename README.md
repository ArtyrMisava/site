# ДУС — локальная карта объектов

ДУС превращается в самостоятельное приложение для Windows. Оно по-прежнему полностью работает без интернета: карта, русские географические подписи, Excel и рабочие данные остаются только на компьютере пользователя.

## Приложение ДУС для Windows

Первый настольный выпуск собирается в один переносной файл `DUS-0.2.0-portable.exe`:

1. Поместите EXE в отдельную папку с правом записи, например `Документы\ДУС`.
2. Дважды нажмите EXE — установка, PowerShell, Node.js и права администратора не нужны.
3. Приложение само откроет локальную карту и создаст рядом папку `site-data`.

В настольной версии уже работают:

- отдельное обычное окно приложения вместо вкладки браузера;
- полностью автономный локальный сервер, скрытый внутри приложения;
- нативное окно выбора Excel-книги и сохранение обратно в тот же `.xlsx`;
- отдельное интерактивное окно карты для второго монитора;
- меню **«Приложение»** для открытия папки данных и безопасного сброса доступа администратора;
- полноэкранный режим по `F11`, масштаб интерфейса и запоминание размера окна;
- хранение данных и локального профиля рядом с EXE, а не в системной папке.

Чтобы продолжить работу с прежними данными, сначала закройте старое окно сервера, затем положите EXE в существующую папку ДУС: приложение подхватит `site-data\dus-data.json`. При переносе на другой компьютер копируйте EXE вместе с папкой `site-data` и связанной Excel-книгой.

Готовый EXE создаётся на компьютере разработчика файлом `BUILD_DESKTOP_WINDOWS.bat`; результат и контрольная сумма SHA-256 появляются в `build\desktop`. Пока EXE не собран, полностью поддерживается прежний запуск через BAT. Первая тестовая сборка ещё не подписана коммерческим сертификатом, поэтому Windows может показать предупреждение SmartScreen.

## Совместимый запуск через браузер

1. Скачайте и полностью распакуйте ZIP проекта в папку, где у пользователя есть право записи, например в `Документы\ДУС`.
2. Дважды нажмите `START_SITE_WINDOWS.bat`.
3. Не закрывайте появившееся окно, пока работаете с ДУС.

Этот вариант использует комплектный `runtime\node.exe` и `server\dus-server.cjs`, затем открывает Edge или Chrome. Пользователю также не нужны PowerShell, отдельно установленный Node.js, `npm`, установка или права администратора. PowerShell оставлен только как резервный вариант на случай повреждения переносного сервера.

Все пользовательские сообщения в `START_SITE_WINDOWS.bat`, `RESET_ADMIN_PASSWORD.bat` и `UPDATE_EXISTING_SITE.bat` выводятся по-русски. Окно запуска показывает фирменную заставку ДУС и понятные сообщения об ошибках.

## Что умеет ДУС

- показывает полностью локальную карту Восточной Европы;
- выводит 37 381 населённый пункт русскими буквами;
- добавляет и редактирует точки и машины;
- позволяет менять иконки точек, включая спутник, домики и собственные изображения;
- показывает ближайший населённый пункт над каждой пользовательской меткой;
- хранит сотрудников точки в связанной книге Excel;
- строит маршруты машин и показывает движение и направление;
- открывает отдельное интерактивное окно карты для второго монитора;
- показывает отключаемую линию боевого соприкосновения и позволяет администратору редактировать её узлы;
- сохраняет точки, машины, маршруты, линию, настройки и защищённые данные доступа в папке ДУС;
- поддерживает полноэкранный режим и не позволяет уйти за границы карты.

## Слои и детализация карты

Кнопка **«Слои карты»** в правом верхнем углу карты предлагает четыре режима:

- **Авто** — обзор, подробная и максимальная карта переключаются при приближении;
- **Обзор** — обзорный слой остаётся включённым при любом масштабе;
- **Подробно** — дороги, реки, города и посёлки доступны независимо от приближения;
- **Максимум** — принудительно используются наиболее подробные локальные тайлы и подписи сёл.

Выбранный режим сохраняется в папке данных и применяется также в отдельном окне карты. Чтобы снова переключать слои приближением, выберите **«Авто»**.

В этом же меню находится независимый переключатель **«Линия боевого соприкосновения»**. Комплектный снимок датирован 11 октября 2026 года и работает без интернета. Дата всегда показывается в меню и легенде; это оценочная линия из открытого источника, а не официальный оперативный документ.

Для ручной корректировки войдите как администратор, откройте **«Слои карты»** и нажмите **«Редактировать линию»**. Узлы можно перетаскивать, добавлять и удалять; также поддерживаются отдельные участки линии. Кнопка **«Исходная»** удаляет ручную правку и возвращает комплектный снимок. Изменённая линия сохраняется в `site-data` и не удаляется при обновлении программы.

Источник и способ подготовки данных описаны в `public/maps/FRONTLINE_DATA_RU.txt`. Новый GeoJSON-снимок можно подготовить командой `python scripts/update_frontline.py --input latest.geojson`.

## Где хранятся данные

Рядом с переносным EXE или файлами ДУС автоматически создаются:

- `site-data\dus-data.json` — текущие данные;
- `site-data\dus-data.json.bak` — предыдущая автоматическая копия;
- `site-data\desktop-profile` — локальный профиль настольного приложения;
- `site-data\desktop-window.json` — сохранённые размер и положение окна.

В основном файле находятся точки, сотрудники, пользовательские иконки, машины, маршруты, настройки карты и данные учётной записи. Сам ПИН-код и код восстановления **никогда не записываются открытым текстом**: сохраняются только их индивидуально засоленные PBKDF2-SHA-256-хеши. Не редактируйте JSON вручную.

Старые данные из браузерного `localStorage` автоматически переносятся в `site-data` при запуске браузерной версии на прежнем адресе `http://127.0.0.1:4173`. Если очень старая установка ещё не создала `dus-data.json`, один раз запустите её через `START_SITE_WINDOWS.bat`, а затем открывайте приложение. Для переноса на другой компьютер копируйте всю папку ДУС вместе с `site-data`.

Связанная книга `.xlsx` остаётся отдельным пользовательским файлом в выбранном месте. ДУС не перемещает исходную Excel-книгу без разрешения пользователя.

## Администратор и восстановление ПИН-кода

При создании администратора ДУС один раз показывает код вида `XXXX-XXXX-XXXX-XXXX`. Сохраните его отдельно от компьютера. На экране входа кнопка **«Забыли PIN? Восстановить»** позволяет ввести имя, этот код и новый ПИН-код. Точки, машины и маршруты при восстановлении не удаляются.

В приложении откройте **«Приложение → Сбросить доступ администратора…»**. ДУС попросит подтверждение, удалит только данные доступа и перезапустит интерфейс. Карта, точки, люди, машины, маршруты и линия сохранятся.

Для браузерного варианта можно использовать прежний способ:

1. закройте окна ДУС и окно локального сервера;
2. запустите `RESET_ADMIN_PASSWORD.bat`;
3. введите `СБРОС` для подтверждения;
4. снова запустите ДУС и создайте новую учётную запись.

Любой человек с доступом на запись к папке ДУС может выполнить полный сброс, поэтому ограничьте доступ к самой папке средствами Windows.

## Обновление существующей установки

Для переносного приложения закройте ДУС и замените старый EXE новым в той же папке. **Не удаляйте `site-data`** — новый выпуск автоматически использует прежние данные.

Для совместимой браузерной версии:

1. Распакуйте новую версию в отдельную временную папку.
2. Закройте браузер с ДУС и старое окно сервера.
3. В **новой** папке запустите `UPDATE_EXISTING_SITE.bat`.
4. Введите путь к старой папке ДУС или перетащите её в окно CMD.
5. После сообщения **«ОБНОВЛЕНИЕ ЗАВЕРШЕНО»** запускайте `START_SITE_WINDOWS.bat` уже из старой папки.

Обновлятор заменяет программу, карту и встроенные ресурсы, но не трогает `site-data`. Предыдущие программные файлы сохраняются в `update-backup`.

## Связь с Excel

В приложении используется обычное системное окно выбора файла Windows. В браузерной версии функция работает в Edge и Chrome. В режиме администратора нажмите **«Привязать Excel»** и выберите `.xlsx`.

Формат книги:

- один обычный лист — одна точка;
- название листа — название точки;
- `A1` пустая, `B1` содержит название точки;
- со строки 2: столбец `A` — ФИО, столбец `B` — звание или должность.

ДУС создаёт скрытый служебный лист `_Карта` для ID, координат и выбранных иконок. Создание, переименование, перемещение и удаление точки обновляют ту же книгу. Не держите книгу открытой в настольном Excel во время сохранения. Пример: `public/templates/points-workbook-template.xlsx`.

## Иконки точек

Откройте точку в режиме администратора и выберите иконку в разделе **«Иконка точки»**. В комплект входят обычная метка, офис, дом, домики, склад, КПП, спутник и штаб. Любую существующую метку можно открыть и заменить её иконку.

Для собственной иконки нажмите **«Загрузить свою»** и выберите PNG, JPG, WebP или SVG размером до 5 МБ. Изображение автоматически уменьшается, сохраняется вместе с точкой и продолжает работать без интернета. Встроенные файлы находятся в `public/icons/places`, а в готовой Windows-сборке — в `offline-site/icons/places`.

## Маршрут машины

1. Войдите как администратор.
2. Откройте машину и нажмите **«Задать маршрут»**.
3. Отметьте точки пути на карте.
4. Нажмите **«Запустить»**.

Машина движется по линии маршрута. Её значок не вращается — направление показывает отдельная стрелка. Одна реальная секунда соответствует одной минуте пути с заданной скоростью.

## Отдельная карта

Кнопка **«Отдельная карта»** открывает синхронизированное интерактивное окно. Его можно перенести на второй монитор. По умолчанию обзор карт связан; кнопка **«Карты связаны»** включает независимый обзор и обратно. Объекты, слои, маршруты и движение синхронизируются локально.

## Офлайн-карта и русские названия

Охват: 14–60° в.д. и 38–61° с.ш. — от Польши и Балкан до Урала и Каспийского моря. Используются 540 локальных WebP-тайлов и локальная база из 37 381 населённого пункта. Все названия населённых пунктов проверяются сборочным скриптом: латинские и локальные написания преобразуются в русские формы, включая исправление `Новий Крим` / `Novyi Krym` на **«Новый Крым»**. При работе обращения к внешним картографическим сервисам не выполняются.

Основа карты — [Natural Earth](https://www.naturalearthdata.com/) (public domain), населённые пункты — [GeoNames](https://www.geonames.org/) (CC BY 4.0). Сведения об используемых данных находятся в `public/maps/MAP_DATA_RU.txt`.

## Разработка и сборка приложения

Для изменения исходного кода нужен Node.js 22 или новее:

```bash
npm ci
npm run dev
```

Полная проверка настольной версии:

```bash
npm run desktop:check
```

Запуск приложения из исходников:

```bash
npm run desktop:dev
```

Сборка переносного Windows EXE выполняется на Windows командой:

```bash
npm run desktop:pack:win
```

Или запустите `BUILD_DESKTOP_WINDOWS.bat`: он сам установит зависимости, выполнит проверки, соберёт EXE и создаст файл контрольной суммы SHA-256. Результат появляется в `build\desktop`.

Архитектура первого настольного выпуска:

- `desktop/main.cjs` — окно Electron, русское системное меню, локальный сервер и безопасные операции с Excel;
- `desktop/preload.cjs` — узкий изолированный мост между интерфейсом и Windows;
- `server/dus-server.cjs` — общий сервер хранения для приложения и прежнего BAT-запуска;
- `dist` — свежая веб-сборка, которая вкладывается внутрь EXE;
- `site-data` — переносимые пользовательские данные рядом с приложением.

Electron запускается с `contextIsolation`, без Node.js в интерфейсе и без доступа страниц к произвольным файлам. Excel читается и записывается только после выбора пользователем через системный диалог. Приложение слушает только `127.0.0.1`.

Для обновления совместимой сборки после `npm run build` содержимое `dist` копируется в `offline-site`. Проверка русских названий выполняется командой `python scripts/russianize-place-labels.py public/maps/places.json`.
