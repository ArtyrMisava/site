# Локус — локальная карта объектов

Одностраничный офлайн-интерфейс для размещения сотрудников, рабочих точек и служебных машин на карте компании.

## Возможности прототипа

- условная городская карта, работающая без интернета;
- увеличенная область наведения у каждой метки;
- карточка точки с таблицей всех сотрудников и их должностей;
- служебные машины со статусом и направлением движения;
- поиск по точкам, ФИО и должностям;
- режим администратора с первичной настройкой имени и PIN;
- добавление, редактирование, удаление и перетаскивание объектов;
- прямая связь с книгой Excel (`.xlsx`): один лист — одна точка;
- создание и удаление листов Excel вместе с точками;
- автоматическое сохранение координат и сотрудников в ту же книгу;
- локальное резервное хранение данных в браузере этого компьютера;
- адаптивный интерфейс для разных размеров экрана.

## Быстрый запуск на Windows без Node.js и npm

1. Скачайте ZIP ветки и **полностью распакуйте** его в отдельную папку.
2. Дважды нажмите `START_SITE_WINDOWS.bat`.
3. Оставьте открывшееся окно запущенным, пока работаете с сайтом.

Браузер откроет локальный адрес автоматически. Готовая сборка находится в `offline-site`, а встроенный PowerShell-сервер не требует установки программ и не обращается в интернет. Подробная инструкция — в `WINDOWS_START_RU.txt`.

## Запуск для разработки

Для изменения исходного кода нужен [Node.js LTS](https://nodejs.org/), в состав которого входит `npm`:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:4173`).

## Проверка и production-сборка

```bash
npm run check
npm run build
npm run preview
```

Готовые статические файлы появляются в каталоге `dist` и не требуют доступа к интернету.

## Связь с Excel

Функция работает в **Google Chrome** и **Microsoft Edge**. В режиме администратора нажмите **«Привязать Excel»** и выберите книгу `.xlsx`.

Структура книги:

- каждый обычный лист соответствует одной точке на карте;
- название листа используется как название точки;
- `A1` содержит подпись `Название места`, `B1` — название точки;
- начиная со строки 2: столбец `A` — ФИО, столбец `B` — звание или должность;
- количество сотрудников на одном листе не ограничено интерфейсом карты.

При первом подключении сайт добавляет очень скрытый служебный лист `_Карта`. В нём хранятся стабильные ID, названия листов и координаты ярлыков. Его не нужно редактировать вручную.

После подключения:

- создание точки создаёт новый оформленный лист;
- переименование точки переименовывает лист;
- редактирование сотрудников обновляет строки A/B;
- перетаскивание ярлыка сохраняет новые координаты;
- удаление точки удаляет связанный лист;
- кнопка **«Обновить из Excel»** перечитывает изменения, сделанные вручную в Excel.

Не держите книгу открытой в настольном Excel во время сохранения с сайта. Перед первым подключением рекомендуется сделать резервную копию. Пример находится в `public/templates/points-workbook-template.xlsx` и скачивается из окна привязки.

## Данные и доступ администратора

При первом нажатии кнопки «Администратор» приложение предложит создать локальное имя пользователя и PIN. PIN хранится в браузере в виде SHA-256-хеша. Объекты карты сохраняются в `localStorage`, а активная административная сессия — в `sessionStorage`.

> Это подход для выбранного сценария одного локального компьютера. Если сайт понадобится нескольким сотрудникам одновременно, хранение и авторизацию следует перенести на локальный сервер с базой данных.
