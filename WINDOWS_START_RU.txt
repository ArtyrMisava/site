КАК ЗАПУСТИТЬ САЙТ НА WINDOWS БЕЗ NPM
======================================

1. Полностью распакуйте скачанный ZIP-архив в отдельную папку.
   Не запускайте файлы прямо внутри окна ZIP-архива.

2. Дважды нажмите файл:

   START_SITE_WINDOWS.bat

3. Откроется окно локального сервера, а затем браузер с сайтом.
   Обычно используется адрес http://127.0.0.1:4173

4. Не закрывайте чёрное окно, пока работаете с сайтом.

5. Для остановки закройте чёрное окно или нажмите в нём Ctrl+C.

Node.js и npm для этого способа НЕ нужны.
Интернет после скачивания архива также не нужен.

РЕАЛЬНАЯ ОФЛАЙН-КАРТА
---------------------
В сборку уже включена реальная карта территории от Киева и Молдовы до
Волгограда, Крыма, Краснодарского края и Северного Кавказа. Дороги, города,
реки и границы загружаются с компьютера, без обращения к картографическим сайтам.

СВЯЗЬ С EXCEL
-------------
Откройте сайт в Microsoft Edge или Google Chrome. Войдите как администратор
и нажмите «Привязать Excel». Каждый обычный лист книги .xlsx станет одной
точкой на карте. Название листа — название точки. В первой строке ячейка
A1 пустая, а B1 содержит название точки без подписи. Данные сотрудников
начинаются со строки 2: A — ФИО, B — звание или должность.

Новые точки создают новые листы и сохраняются в тот же файл. Не держите
книгу открытой в Excel во время сохранения с сайта. Перед первым запуском
рекомендуется сделать резервную копию. Пример книги скачивается из окна связи.

Если Windows показывает предупреждение о запуске BAT-файла, убедитесь,
что архив скачан из вашего репозитория ArtyrMisava/site. Файл запускает
только локальный PowerShell-сервер и не подключается к внешним сервисам.
