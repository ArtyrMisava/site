ДУС ДЛЯ WINDOWS: ПРИЛОЖЕНИЕ И СОВМЕСТИМЫЙ ЗАПУСК
================================================

ПРИЛОЖЕНИЕ ДЛЯ ПК
-----------------
1. Поместите файл DUS-0.2.0-portable.exe в отдельную папку с правом записи.
2. Дважды нажмите EXE. Установка, PowerShell, npm и права администратора
   НЕ нужны. Интернет для работы также не нужен.
3. Папка site-data будет создана рядом с EXE. Не удаляйте её при обновлении.
4. Для старых данных закройте прежний сервер и положите EXE в прежнюю папку
   ДУС рядом с site-data.

В меню «Приложение» можно открыть папку данных или сбросить доступ
администратора без удаления точек, машин, маршрутов и линии. Клавиша F11
включает полноэкранный режим. Excel выбирается через обычное окно Windows.

Пока тестовый EXE не подписан сертификатом, Windows может показать
предупреждение SmartScreen. Разработчик создаёт EXE запуском
BUILD_DESKTOP_WINDOWS.bat на компьютере с Node.js 22 или новее.

СОВМЕСТИМЫЙ ЗАПУСК ЧЕРЕЗ БРАУЗЕР
--------------------------------
Все подсказки в файлах запуска, сброса доступа и обновления написаны по-русски.

1. Полностью распакуйте скачанный ZIP-архив в отдельную папку.
   Не запускайте файлы прямо внутри окна ZIP-архива.

2. Дважды нажмите START_SITE_WINDOWS.bat.

3. Запустится комплектный runtime\node.exe с локальным сервером, после чего
   откроется браузер. Обычно используется адрес http://127.0.0.1:4173

4. Не закрывайте окно сервера, пока работаете с ДУС.

5. Для остановки закройте окно или нажмите в нём Ctrl+C.

ДАННЫЕ В ПАПКЕ ДУС
-------------------
Точки, люди, машины, маршруты, линия боевого соприкосновения, настройки,
хеш ПИН-кода и хеш кода восстановления сохраняются в site-data\dus-data.json.
Предыдущая автоматическая копия находится в site-data\dus-data.json.bak.
Сам ПИН-код открытым текстом не сохраняется.

При первом запуске новой версии старые данные браузера автоматически переносятся
в эту папку. Для переноса на другой компьютер копируйте всю папку ДУС вместе с
site-data. Связанная книга Excel остаётся отдельным файлом в выбранном месте.

ВОССТАНОВЛЕНИЕ ПИН-КОДА
-----------------------
При создании администратора сохраните показанный код восстановления. На экране
входа нажмите «Забыли PIN? Восстановить», введите код и задайте новый ПИН-код.

В приложении выберите «Приложение» → «Сбросить доступ администратора…».
Если используется браузерный вариант, закройте ДУС и сервер, затем запустите:

   RESET_ADMIN_PASSWORD.bat

Введите СБРОС. Учётная запись будет сброшена, но точки, люди, машины,
маршруты и линия останутся. После этого запустите ДУС и создайте новый доступ
администратора.

ОБНОВЛЕНИЕ СТАРОГО САЙТА
------------------------
1. Распакуйте новую версию в отдельную папку.
2. Закройте старый сайт и старое окно сервера.
3. В новой папке запустите UPDATE_EXISTING_SITE.bat.
4. Введите или перетащите в CMD путь к старой папке ДУС.
5. После сообщения «ОБНОВЛЕНИЕ ЗАВЕРШЕНО» запускайте
   START_SITE_WINDOWS.bat в старой папке.

Папка site-data не заменяется. Старые программные файлы копируются в
update-backup.

СЛОИ КАРТЫ
-----------
Кнопка «Слои карты» позволяет выбрать «Авто», «Обзор», «Подробно» или
«Максимум». Ручной слой работает при любом приближении. Для автоматического
переключения при масштабировании снова выберите «Авто».

РУССКИЕ НАЗВАНИЯ
-----------------
В локальной базе 37 381 населённый пункт. Все подписи приведены к русскому
написанию; латинские местные названия на карте не используются.

КАРТА НА ВТОРОМ МОНИТОРЕ
------------------------
Нажмите «Отдельная карта». Откроется интерактивное окно, которое можно перенести
на второй монитор. Метки, слои, фильтры, маршруты и движение синхронизируются.
В браузерной версии при необходимости разрешите всплывающие окна для локального адреса.

СВЯЗЬ С EXCEL
-------------
В приложении файл выбирается через обычное окно Windows. В браузерной версии
используйте Microsoft Edge или Google Chrome. Войдите как администратор и
нажмите «Привязать Excel». Один обычный лист книги .xlsx соответствует одной
точке. Название листа — название точки. A1 пустая, B1 содержит название точки.
Со строки 2: A — ФИО, B — звание или должность.

Не держите книгу открытой в Excel во время записи. Перед первым подключением
сделайте резервную копию.
