ПЕРЕНОСНОЙ СЕРВЕР ДУС
======================

node.exe — официальный переносной Node.js v22.22.1 для Windows x64.
Он не устанавливается в систему и запускает только локальный файл
server\dus-server.cjs. Сервер слушает 127.0.0.1, раздаёт offline-site и
сохраняет состояние в site-data\dus-data.json.

Лицензия Node.js и включённых компонентов находится в NODE_LICENSE.txt.
Источник: https://nodejs.org/ и npm-пакет node-win-x64@22.22.1.
